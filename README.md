# Stock Market Sentiment Analysis Chatbot

An **AI-powered stock market chatbot** that combines **LLaMA-3, Natural Language Processing, sentiment analysis, and real-time financial APIs** to provide users with intelligent responses and market insights. The system retrieves stock data, company information, and financial news while analyzing news sentiment to provide additional market context.

## Features

* 🤖 **AI-Powered Chatbot** using **LLaMA-3** for intelligent responses to financial queries.
* 📊 **Real-Time Stock Market Data** for monitoring current market information.
* 📰 **Financial News Retrieval** to provide relevant and recent market-related news.
* 📈 **Stock & Company Information** including price and company-specific details.
* 💭 **Sentiment Analysis** using **NLTK VADER** to analyze financial news.
* 🔴 **Sentiment Classification** into **Positive, Neutral, or Negative** categories.
* 🔗 **Financial API Integration** with **Finnhub** and **Yahoo Finance** for market and company data.
* 🌐 **Interactive Web Interface** developed using **HTML5, CSS3, and JavaScript**.
* ⚡ **FastAPI Backend** for efficient API communication and request handling.

## Technologies Used

## Project Objective

The objective of this project is to integrate **Artificial Intelligence, Natural Language Processing, sentiment analysis, and real-time financial data** into a single interactive platform. It helps users explore stock market information, retrieve company-specific data, access financial news, and understand the overall sentiment associated with market-related news.

## Key Functionality

The chatbot accepts **natural-language queries** related to selected companies or stocks. Based on the query, the system retrieves relevant **stock prices, company information, and financial news** through integrated financial APIs.

The retrieved financial news is processed using **VADER sentiment analysis**, which evaluates the textual content and classifies it as **Positive, Neutral, or Negative**. The chatbot then combines the retrieved financial information and sentiment insights to provide users with a more comprehensive view of the selected stock or company.

## Outcome

The project demonstrates the practical integration of **Generative AI, NLP, sentiment analysis, API integration, and web development** to build an interactive financial information assistant. It provides a centralized interface for querying market information and gaining additional context from financial news sentiment.
